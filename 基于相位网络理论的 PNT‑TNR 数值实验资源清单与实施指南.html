基于相位网络理论的 PNT‑TNR 数值实验资源清单与实施指南

本指南旨在帮助研究者从零开始搭建并执行 PNT‑TNR 数值实验，以验证固定点处普适校准关系 Rn=nR_n = n 的存在性。我们将以 2+1 维 SU(2)_k 量子群自旋网（对应理论阶段II）为主要目标，因为其计算复杂度适中，且已有 Dittrich 等人的工作作为参考。

一、所需资源清单

1. 硬件资源

  • 工作站：建议配置不低于 64 核 CPU、256 GB RAM，配备 SSD 存储（至少 2 TB）。用于小规模晶格（如 32332^3）的初步扫描和算法调试。

  • 小型集群：用于大规模参数扫描（如 64364^3 晶格，多个 kk 值）。要求：每个节点 32 核以上，InfiniBand 网络，共享存储。

  • GPU（可选）：若使用基于 GPU 的线性代数库（如 cuBLAS），可加速 SVD 和大规模矩阵运算。

2. 软件资源

  • 操作系统：Linux（推荐 Ubuntu 20.04 或 CentOS 7），Windows 可通过 WSL2 部分支持。

  • 编程语言：

    • C++17：核心数值计算（6j 符号、TNR 循环）。

    • Python 3.8+：参数扫描、数据处理、可视化（NumPy, SciPy, Matplotlib, h5py）。

  • 关键库：

    • sl2cfoam-next：用于计算 SU(2) 和 SU_q(2) 的 6j/15j 符号。需从其 GitHub 仓库编译。

    • Eigen3：高性能线性代数库（矩阵运算、SVD）。

    • LAPACK / BLAS：底层线性代数（OpenBLAS 或 Intel MKL）。

    • MPI（可选）：用于并行化参数扫描。

    • HDF5：存储大量张量数据和扫描结果。

    • CMake：构建系统。

  • 辅助工具：

    • Git：版本控制。

    • Docker（可选）：创建可复现的计算环境。

3. 数据资源

  • 6j 符号预计算表：对于每个 (k,jmax⁡)(k, j_{\max})，需要预先计算所有可能组合的 6j 符号。sl2cfoam-next 可生成这些数据，存储为二进制文件或 HDF5 数据库。

  • 初始张量：满足高斯约束的随机四阶张量，用于启动 TNR 迭代。

4. 人员技能

  • 理论物理背景：熟悉圈量子引力、自旋泡沫、重整化群。

  • 数值计算经验：精通 C++ 编程、并行计算、数值线性代数。

  • 数据分析：Python 数据处理、统计分析、可视化。

5. 时间估计

  • 环境搭建：2 周

  • 代码开发：8–12 周

  • 参数扫描：4–8 周（取决于计算资源）

  • 数据分析与论文撰写：4–6 周

总耗时约 6–9 个月，视团队规模和计算资源而定。

二、实施步骤指南

步骤 0：环境搭建

  1. 安装依赖：

    sudo apt update
sudo apt install build-essential cmake git libeigen3-dev libhdf5-dev openmpi-bin libopenmpi-dev python3-pip
pip3 install numpy scipy matplotlib h5py mpi4py

  2. 编译 sl2cfoam-next：

    git clone https://github.com/yourfork/sl2cfoam-next.git
cd sl2cfoam-next
mkdir build && cd build
cmake .. -DCMAKE_INSTALL_PREFIX=/usr/local
make -j4
sudo make install

    测试安装：运行自带的示例程序计算 6j 符号。

  3. 创建项目目录结构：

    PNT-TNR/
├── src/            # C++ 源代码
├── python/         # Python 脚本
├── data/           # 存储预计算 6j 符号和结果
├── config/         # 参数配置文件
├── scripts/        # 作业提交脚本
└── docs/           # 文档

步骤 1：预计算 6j 符号

针对目标量子群参数 kk（如 k=4,6,10k=4,6,10）和截断 jmax⁡=(k−2)/2j_{\max} = (k-2)/2，生成所有需要的 6j 符号。

  • 使用 sl2cfoam-next 的 compute_6j 工具，遍历所有可能的自旋组合。

  • 将结果存储为 HDF5 文件，例如 sixj_k4.h5，包含数据集 {j1,j2,j3,j4,j5,j6: value}。

  • 对于边张量 TeT_e 的构造，需要调用这些 6j 符号求和。可以在 C++ 中直接读取 HDF5 文件，或者预计算所有 Te(j1,j2,j3,j4)T_e(j_1,j_2,j_3,j_4) 并存储为四维数组。

步骤 2：实现保高斯约束 TNR 核心

2.1 张量类设计：在 C++ 中定义 Tensor 类，支持基本运算（缩并、SVD、范数等）。利用 Eigen 的 Matrix 或 Tensor 模块。

2.2 高斯约束投影：

  • 实现函数 project_to_gauss(const Tensor& T)，输入四阶张量 TijklT_{ijkl}，输出投影到高斯约束子空间后的张量。

  • 投影算法：对于给定指标 i,j,k,li,j,k,l，需计算其是否满足三角不等式且存在中间角动量。可通过查找预计算的 6j 符号来判定，并使用正交关系进行投影。

2.3 粗粒化变换：

  • 输入：四个边张量 Te1,Te2,Te3,Te4T_{e1}, T_{e2}, T_{e3}, T_{e4}（按块排列）。

  • 缩并：按照超立方体块的连接性缩并成一个高阶张量 TblockT_{\text{block}}。

  • SVD：将 TblockT_{\text{block}} 重排为矩阵，计算奇异值分解，保留前 DD 个奇异值（DD 可设定为 (jmax⁡+1)2(j_{\max}+1)^2 或自适应截断）。

  • 重构新的边张量：将截断后的矩阵分解为左右两个因子，再投影到高斯约束子空间。

2.4 迭代收敛：主循环中，对每一层粗粒化，计算新旧张量之间的希尔伯特-施密特距离，若小于阈值（如 10−810^{-8}）则停止。

步骤 3：扫描参数空间定位临界点

3.1 固定截断 jmax⁡j_{\max}，扫描耦合常数 β\beta（例如从 0.1 到 10，步长 0.02）。
3.2 对每个 β\beta：

  • 初始化随机边张量（满足高斯约束）。

  • 执行若干次粗粒化迭代（例如 b=2,4,8b=2,4,8），每次迭代后记录顶点张量的第一大奇异值 χ1\chi_1 和第二大奇异值 χ2\chi_2。

  • 计算比值 R(β,b)=χ2/χ1R(\beta, b) = \chi_2 / \chi_1。

3.3 交点定位：绘制不同 bb 下的 R(β,b)R(\beta, b) 曲线，寻找所有曲线交点的 β\beta 值，即为临界点 βc\beta_c。可采用自动算法（如寻找最小方差点）。

步骤 4：深度粗粒化至固定点

在 βc\beta_c 处，从新的随机初始化开始，执行上述 TNR 迭代，直到收敛到固定点张量 Te∗T_e^*。记录收敛后的张量以及每次迭代的中间结果。

步骤 5：提取可观测量并计算 RnR_n

5.1 总几何相位 Φgtot\Phi_g^{\text{tot}}：

  • 在收敛后的网络上，选择最小的闭合回路（如一个晶格单元的表面）。

  • 从边张量重构群元 UeU_e：边张量本身不是群元，但可通过求解特征值问题得到“平均”群元。一种简单方法：利用威尔逊圈期望值 ⟨Wγ⟩\langle W_\gamma \rangle 代替直接相位。威尔逊圈可通过张量网络的收缩计算，得到复数，其幅角即为几何相位。

  • 计算回路上的威尔逊圈期望值：将回路上的边张量按顺序缩并，最后取迹。由于张量网络是离散的，需实现回路收缩算法。

5.2 总质量 MtotalM_{\text{total}}：

  • 在连续极限下，质量密度可由能量-动量张量给出。在离散网络中，可借助转移矩阵方法：构造系统沿时间方向的转移矩阵 TT，其最大特征值 λ0\lambda_0 给出真空能量密度。对于有限区域，总质量 MM 与转移矩阵的特征值有关，但实现复杂。

  • 替代方案：利用普适校准关系本身。若假设系统在固定点处满足标度不变性，则总几何相位与总质量应成正比，比例系数由整数 nn 决定。我们实际上要验证的就是这个比例是否为整数，因此只需计算 Φgtot\Phi_g^{\text{tot}} 和 MtotalM_{\text{total}} 的相对值，并与理论预期对比。

  • 具体数值方法：从固定点张量构造系统的配分函数，通过求导得到能量密度。这需要定义哈密顿量，在自旋泡沫框架中较困难。另一种思路：利用面积定律，在固定点处威尔逊圈的面积律行为给出弦张力，从而反推能量尺度。这些方法需进一步研究。

鉴于数值复杂性，建议初期采用简化方案：在 2+1 维模型中，几何相位与质量的关系可通过文献中已有的固定点解（如 Dittrich 等人的结果）进行标定，不必直接计算绝对质量，而是验证 RnR_n 是否与整数一致。例如，对于已知的 BF 固定点，其几何相位为零，对应 n=0n=0；对于非平庸固定点，预期 nn 为正整数。可以通过比较不同固定点的 Φgtot\Phi_g^{\text{tot}} 来推断 nn。

5.3 计算 RnR_n：
在自然单位制下，Rn=Φgtot/MtotalR_n = \Phi_g^{\text{tot}} / M_{\text{total}}。若无法直接得到 MtotalM_{\text{total}}，可用其他可观测量替代，如关联长度、威尔逊圈面积律系数等，这些量与质量有确定关系。但最直接的方法是，在 2+1 维模型中，质量与几何相位有简单关系（例如，从黑洞类比 cC⋅M=nℏcC \cdot M = n\hbar 可推导出 M∝1/CM \propto 1/C，而 C∝ΦgC \propto \Phi_g，故 M∝1/ΦgM \propto 1/\Phi_g）。这需要根据具体模型定出比例常数。

步骤 6：截断外推与误差分析

对多个 jmax⁡j_{\max}（例如 5,7,9）重复上述步骤，得到 Rn(jmax⁡)R_n(j_{\max}) 序列。使用公式

Rn(jmax⁡)=n+Ae−αjmax⁡+Bjmax⁡−ΔR_n(j_{\max}) = n + A e^{-\alpha j_{\max}} + B j_{\max}^{-\Delta}

拟合外推至 jmax⁡→∞j_{\max}\to\infty，得到极限值 nn。检查拟合优度，并估计误差。

步骤 7：交叉验证与结果发布

  • 对不同大小的闭合回路重复计算，确保结果一致。

  • 对不同初始随机种子重复，确认收敛唯一性。

  • 与 Dittrich 等人的固定点分类进行比对，确认不同整数 nn 对应不同普适类。

  • 将代码、数据、分析脚本开源，并提供详细文档。

三、关键注意事项

  1. 高斯约束的实现：必须确保投影操作正确，否则 TNR 会偏离物理子空间。建议先用小规模测试验证约束保持性。

  2. SVD 截断：截断维数 DD 的选择影响粗粒化精度。可动态调整，使截断误差小于预设阈值。

  3. 威尔逊圈的计算：在收缩回路时，需注意张量的缩并顺序，避免过大的中间张量。可采用从边界逐步缩并的方法。

  4. 质量提取的替代方案：由于直接定义困难，可考虑使用关联长度作为替代。在临界点附近，关联长度 ξ\xi 发散，其标度行为与质量有关。通过测量不同 β\beta 下的 ξ\xi，可拟合出临界指数 ν\nu，并与 λmax\lambda_{\text{max}} 对比，间接验证理论。

  5. 并行化：参数扫描天然可并行，使用 MPI 将不同 β\beta 或不同 jmax⁡j_{\max} 分配给多个节点。

四、预期结果与成功判据

  • 临界点：观察到 R(β,b)R(\beta, b) 曲线在不同 bb 下相交于 βc\beta_c。

  • 固定点收敛：迭代后张量距离指数衰减至阈值以下。

  • 整数 nn：计算出的 RnR_n 在数值误差内接近整数（例如 ∣Rn−round(Rn)∣<10−3|R_n - \text{round}(R_n)| < 10^{-3}），且随 jmax⁡j_{\max} 增大而收敛。

  • 普适类匹配：不同 kk 值得到的 nn 应与 Dittrich 等人报道的固定点结构对应（例如 k=4k=4 可能对应 n=1n=1）。

若上述结果均成立，则验证了相位网络理论的核心预言，为连续极限存在性提供了强有力的数值证据。
