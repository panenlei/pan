第一阶段执行：复现与借鉴——详细实施方案

根据混合策略，第一阶段的核心是“研读Dittrich 2016论文，提取算法细节，复现SU(2)_k自旋网TNR算法”。以下基于搜索结果提供具体实施方案。

一、Dittrich 2016论文核心算法解析

1.1 论文基本信息

目标文献：Bianca Dittrich, Sebastian Mizera, Sebastian Steinhaus, “Decorated tensor network renormalization for lattice gauge theories and spin foam models”, New Journal of Physics 18 (2016) 053009 [arXiv:1409.2407]

核心贡献：提出了装饰张量网络重整化（decorated tensor network renormalization）算法，专门处理具有规范对称性的晶格规范理论和自旋泡沫模型。该算法的关键创新是能够在粗粒化过程中显式保持规范对称性，并可直接解释固定点张量。

1.2 算法关键思想

根据论文摘要和引言部分，该算法的核心设计理念是：

  1. 避免冗余求和：标准张量网络在处理规范理论时，会因规范自由度而过参数化。新算法通过引入“装饰”结构来避免这种冗余。

  2. 适用于量子群模型：特别指出，基于量子群（单位根处）的模型具有自然的初始键维数截断，适用于带有宇宙学常数的引力模型。

  3. 算法优势：相比之前的工作，该算法效率显著提高，并能直接获取某些期望值和关联函数。

1.3 算法框架转化为伪代码

基于论文描述，我将核心算法提取为以下伪代码：

算法：装饰张量网络重整化（适用于非阿贝尔规范理论）

输入：初始边张量集合 {T_e}，截断参数 D_max，迭代次数 N
输出：粗粒化后的固定点张量 T*

1. 初始化：
   - 对每个面 f，根据群表示计算面权重 ω(j_f)
   - 对每个边 e，根据其邻接的面构建初始四阶张量 T_e

2. 对于 iteration = 1 to N 执行：
   a. 块划分：将晶格划分为 2×2×2×2 的超立方体块
   
   b. 对每个块执行：
      - 缩并块内所有边张量，得到块张量 T_block
      - 将 T_block 重排为矩阵 M
      - 对 M 执行奇异值分解：M = U S V†
      - 保留最大的 D 个奇异值，得到截断矩阵 M_trunc
      - 将 M_trunc 分解为两个新的边张量 T_left, T_right
   
   c. 约束保持投影：
      - 对新边张量执行规范约束投影 P_gauss
      - 确保投影后的张量满足高斯约束（即围绕每个顶点的表示求和为零）
   
   d. 计算收敛性：‖T_new - T_old‖ < ε 则停止

3. 返回收敛后的张量 T*

二、SU(2)_k 自旋网TNR算法复现步骤

2.1 理论基础

Dittrich等人在2016年另一篇重要论文中明确指出：

“In order to perform these simulations we have substantially adapted tensor network algorithms, which we discuss in detail as they can be of use in other contexts.”

这意味着他们的算法细节是公开可用的，可以作为我们复现的蓝图。

2.2 复现的具体步骤

第一步：理解模型结构

对于SU(2)_k×SU(2)_k量子群，需要理解：

  • 面自旋 jfj_f 的取值范围：jf≤(k−2)/2j_f \le (k-2)/2

  • 顶点振幅由量子6j符号给出

  • 简单性约束（simplicity constraints）的实现方式

第二步：张量网络构造

根据论文描述，自旋网的配分函数可以写成：

Z = Σ_{j_f} Π_f ω(j_f) Π_e T_e({j_f}) Π_v A_v({j_f})

其中：

  • ω(jf)ω(j_f) 是面权重

  • TeT_e 是边张量（四阶）

  • AvA_v 是顶点振幅（由量子6j符号构成）

第三步：保高斯约束TNR的实现

论文详细讨论了如何通过引入额外结构来保持规范对称性：

  • 高斯约束的数学形式：围绕每个顶点的表示求和为零

  • 投影算子 PGaussP_{Gauss} 的构造方法

  • 如何在SVD截断后保持约束

第四步：固定点识别

参考Dittrich等人的方法，固定点识别标准：

  • BC intertwiner模型本身是固定点，构成2D拓扑相

  • BC spin net模型流向多个不同的拓扑相

  • 他们发现了新的非平凡相，其中简单性约束的非平凡版本成立

2.3 验证基准

为了验证复现的正确性，可以用以下已知结果作为基准：

模型已知行为验证指标
BC intertwiner模型固定点，2D拓扑相粗粒化后张量不变
BC spin net模型流向多个拓扑相出现固定点，相变非二阶
EPRL/FK模型复杂动力学，不收敛到固定点粗粒化流持续变化

三、sl2cfoam-next 集成方案

3.1 库的功能

sl2cfoam-next是用于计算自旋泡沫振幅的高性能库，支持：

  • SU(2) 和 SU_q(2) 的6j符号

  • 15j符号（用于4维模型）

  • 量子群形变（k为参数）

3.2 集成步骤

  1. 编译安装：

git clone https://github.com/yourfork/sl2cfoam-next.git
cd sl2cfoam-next
mkdir build && cd build
cmake .. -DCMAKE_INSTALL_PREFIX=/usr/local
make -j4
sudo make install

  1. 接口封装：

    • 创建C++包装类，封装6j符号查询功能

    • 对给定的(j1,j2,j3,j4,j5,j6)和k，返回量子6j符号值

    • 预计算所有可能的组合，存入HDF5文件加速访问

  2. 与TNR算法集成：

    • 在顶点振幅计算中调用6j符号库

    • 在边张量构造中使用6j符号进行求和

    • 在约束投影中利用6j符号的正交关系

3.3 性能优化建议

根据论文的讨论：

  • 对于量子群模型，键维度自然截断，初始计算量可控

  • 对于小k值（如k=4,6），可完整枚举所有自旋组合

  • 建议先在小k值上验证算法正确性，再逐步增大k
