基于相位网络理论的 PNT‑TNR 数值实验方案：验证固定点 Rn=nR_n = n 的存在性

本方案旨在通过数值模拟，寻找相位网络理论（PNT）中满足普适校准全局关系 Rn=nR_n = n 的固定点。该验证是 PNT 连续极限存在性定理的核心判据。我们将基于已有的自旋泡沫与张量网络重整化群（TNR）技术，利用开源工具实现可复现的数值实验。

一、实验目标

  1. 定位临界点：在参数空间（如耦合常数 β\beta、截断 jmax⁡j_{\max}）中找到系统发生相变的位置 βc\beta_c。

  2. 收敛到固定点：在 βc\beta_c 处执行深度粗粒化，使边张量 TeT_e 迭代收敛到固定点 Te∗T_e^*。

  3. 计算关键比值：在固定点处提取总几何相位 Φgtot\Phi_g^{\text{tot}} 和总动力学相位变化率 ∣Φ˙dtot∣|\dot{\Phi}_d^{\text{tot}}|，验证无量纲量 Rn=Φgtot∣Φ˙dtot∣ tPR_n = \frac{\Phi_g^{\text{tot}}}{|\dot{\Phi}_d^{\text{tot}}| \, t_P} 是否为整数 nn（在数值误差范围内）。

  4. 外推至连续极限：通过改变截断 jmax⁡j_{\max}，外推至 jmax⁡→∞j_{\max} \to \infty，确认整数量子化的稳定性。

二、理论基础与关键公式回顾

  • 普朗克时间：tP=ℏmPc2=ℏGc5t_P = \frac{\hbar}{m_P c^2} = \sqrt{\frac{\hbar G}{c^5}}（数值模拟中常取 ℏ=c=G=1\hbar = c = G = 1，此时 tP=1t_P = 1，mP=1m_P = 1）。

  • 总几何相位：对闭合曲面 ∂Σ\partial \Sigma，Φgtot=∮∂ΣdΦgeom=arg⁡Tr⁡P∏e∈∂ΣUe\Phi_g^{\text{tot}} = \oint_{\partial \Sigma} d\Phi_{\text{geom}} = \arg \operatorname{Tr} \mathcal{P} \prod_{e \in \partial \Sigma} U_e（威尔逊圈）。

  • 总动力学相位变化率：∣Φ˙dtot∣=Mtotalc2ℏ|\dot{\Phi}_d^{\text{tot}}| = \frac{M_{\text{total}} c^2}{\hbar}，其中 MtotalM_{\text{total}} 是曲面所围区域的总质量（可从局域能量密度积分得到）。

  • 无量纲比值：Rn=Φgtot∣Φ˙dtot∣ tPR_n = \frac{\Phi_g^{\text{tot}}}{|\dot{\Phi}_d^{\text{tot}}| \, t_P}。在固定点处应满足 Rn=nR_n = n（整数）。

三、数值实验步骤

3.1 选择模型与开源工具

  • 模型：优先采用 2+1 维 SU(2)_k 量子群自旋网（对应阶段II），因其已在 Dittrich 等人工作中被证明存在丰富的固定点结构，且计算复杂度较低。也可逐步升级至 4D 超立方体模型（阶段III）。

  • 开源工具：

    • sl2cfoam-next：C++ 库，高效计算 SU(2) 和 SU_q(2) 的 6j/15j 符号，用于顶点振幅和边张量的生成。

    • TensorNetwork（Python）或 iTensor（C++）：通用张量网络库，用于实现保高斯约束的 TNR 算法。

    • Eigen / LAPACK：用于 SVD 和线性代数运算。

    • 自定义 Python 脚本：用于参数扫描、数据分析与可视化。

3.2 网络构建与初始张量生成

  1. 选择复形：对 2+1 维，采用三角剖分或六边形格点；对 4 维，采用超立方体对偶复形（如 242^4 晶格）。

  2. 预计算边张量 TeT_e：

    • 对于 SU(2) 情形，Te(j1,j2,j3,j4)=∑x(2x+1){j1j2xj4j30}{xj3j4j2j10}T_e(j_1,j_2,j_3,j_4) = \sum_x (2x+1) \begin{Bmatrix} j_1 & j_2 & x \\ j_4 & j_3 & 0 \end{Bmatrix} \begin{Bmatrix} x & j_3 & j_4 \\ j_2 & j_1 & 0 \end{Bmatrix}。

    • 对于 SU_q(2) 情形，将 6j 符号替换为量子 6j 符号，并截断至 jmax⁡=(k−2)/2j_{\max} = (k-2)/2。

    • 利用 sl2cfoam-next 批量计算所有需要的 6j 符号，存储为字典供调用。

  3. 顶点振幅 AvA_v：对于 4D，需预计算 15j 符号（同样借助 sl2cfoam-next）。

3.3 扫描参数空间定位临界点

采用本征微观态重整化群方法，通过不同系统尺寸下的张量网络收缩来定位相变点。

  1. 固定截断 jmax⁡j_{\max}（例如 jmax⁡=5,7,9,…j_{\max}=5,7,9,\dots）。

  2. 选取系统尺寸 LL（如 L=8,16,32L=8,16,32 的晶格）。

  3. 对每个 β\beta（扫描范围根据经验设定，例如 0.1≤β≤100.1 \le \beta \le 10，步长 0.020.02）：

    • 构建张量网络。

    • 执行粗粒化至不同深度 bb，得到不同有效尺度下的边张量。

    • 计算可观测 R(β,b)=⟨χ2⟩⟨χ1⟩R(\beta, b) = \frac{\langle \chi_2 \rangle}{\langle \chi_1 \rangle}，其中 χ1,χ2\chi_1,\chi_2 是顶点张量的第一大、第二大奇异值。

  4. 寻找不动点：绘制 R(β,b)R(\beta, b) 曲线，不同 bb 的交点对应临界点 βc\beta_c。该点满足 ξ→∞\xi \to \infty。

3.4 深度粗粒化至固定点

在 βc\beta_c 处，从随机初始张量开始，执行迭代粗粒化：

  1. 初始化：生成随机满足高斯约束的边张量 Te(0)T_e^{(0)}（可通过投影随机张量到约束子空间）。

  2. 粗粒化变换 R\mathcal{R}：

    • 将相邻 2×2×2×22\times2\times2\times2 块内的边张量缩并成块张量 TblockT_{\text{block}}。

    • 对 TblockT_{\text{block}} 进行 SVD，保留最大 DD 个奇异值（DD 需根据截断 jmax⁡j_{\max} 调整，例如 D=(jmax⁡+1)2D = (j_{\max}+1)^2）。

    • 投影到高斯约束子空间（利用 6j 符号的正交关系）。

    • 输出新的边张量 Te(b+1)T_e^{(b+1)}。

  3. 迭代：重复步骤 2，直到 ∥Te(b+1)−Te(b)∥HS<ϵ\|T_e^{(b+1)} - T_e^{(b)}\|_{\text{HS}} < \epsilon（例如 ϵ=10−8\epsilon = 10^{-8}），认为收敛到固定点 Te∗T_e^*。

3.5 提取关键可观测量

在固定点处，对网络中的一个代表性闭合曲面 ∂Σ\partial \Sigma（如最小晶格单元的表面）计算：

  1. 总几何相位 Φgtot\Phi_g^{\text{tot}}：

    • 沿 ∂Σ\partial \Sigma 的所有边顺序取群元素（需从边张量重构群元）。重构方法：由于边张量 TeT_e 本身不是群元，但可通过其奇异值分解提取最大奇异值对应的“平均”群元，或利用特征标展开反解。

    • 计算路径有序积 Uloop=P∏e∈∂ΣUeU_{\text{loop}} = \mathcal{P} \prod_{e \in \partial \Sigma} U_e。

    • 取迹并求幅角：Φgtot=arg⁡Tr⁡Uloop\Phi_g^{\text{tot}} = \arg \operatorname{Tr} U_{\text{loop}}（模 2π2\pi，通常取主值在 (−π,π](-\pi,\pi]）。

  2. 总质量 MtotalM_{\text{total}}：

    • 从顶点动力学相位变化率导出质量密度。在连续极限下，质量密度与局域能量有关。在离散网络中，可近似为曲面内所有顶点质量之和。每个顶点的质量 mvm_v 可由其邻边张量的动力学相位变化率估算，或通过求解局部特征值得到（较复杂）。替代方案：利用普适校准关系的积分形式，直接从总几何相位和粗粒化参数反推质量。但更直接的是采用“质量算子”：

      • 在固定点处，系统的哈密顿量（或转移矩阵）的特征值给出了总能量。通过求解转移矩阵的最大特征值 λ0\lambda_0，可得到总能量 E=−ℏln⁡λ0/ΔtE = -\hbar \ln \lambda_0 / \Delta t，从而 Mtotal=E/c2M_{\text{total}} = E/c^2。

      • 在欧几里得路径积分中，配分函数 ZZ 与能量有关，但直接计算有限体积的 ZZ 较困难。通常通过威尔逊圈的面积律或关联长度来反推。

    • 鉴于数值复杂性，一个实用方法是：在粗粒化过程中，同时计算块内所有顶点的动力学相位变化率之和（需定义动力学相位在顶点上的分布）。这需要额外的假设，但可在简化模型中先行测试。

  3. 计算比值：

    Rnum=Φgtot(Mtotalc2/ℏ)⋅tP=ΦgtotMtotaltP⋅(c2/ℏ).R_{\text{num}} = \frac{\Phi_g^{\text{tot}}}{(M_{\text{total}} c^2/\hbar) \cdot t_P} = \frac{\Phi_g^{\text{tot}}}{M_{\text{total}} t_P \cdot (c^2/\hbar)}.

    在自然单位制（ℏ=c=1,G=1\hbar=c=1, G=1）下，tP=1t_P = 1，mP=1m_P = 1，则 Rnum=Φgtot/MtotalR_{\text{num}} = \Phi_g^{\text{tot}} / M_{\text{total}}。需验证其是否为整数 nn。

3.6 截断外推与误差分析

对多个截断 jmax⁡=5,7,9,…j_{\max} = 5,7,9,\dots 重复上述过程，得到 Rnum(jmax⁡)R_{\text{num}}(j_{\max})。预期其随 jmax⁡j_{\max} 增大而趋于某个整数 nn。采用有限尺度标度拟合：

Rnum(jmax⁡)=n+Ae−αjmax⁡+Bjmax⁡−Δ+⋯ ,R_{\text{num}}(j_{\max}) = n + A e^{-\alpha j_{\max}} + B j_{\max}^{-\Delta} + \cdots,

外推至 jmax⁡→∞j_{\max} \to \infty。检查外推值是否稳定，且与整数 nn 的偏差小于统计误差（如 10−310^{-3}）。

3.7 交叉验证

  • 对不同大小的闭合曲面（如 2×22\times2 块、4×44\times4 块）重复上述计算，所得 RnR_n 应一致。

  • 对不同初始随机种子重复，确认收敛值的唯一性。

  • 与已知 Dittrich 等人的固定点分类进行比对，确认不同整数 nn 对应不同普适类。

四、可行性分析

4.1 技术可行性

  • 张量网络 TNR 算法：保高斯约束 TNR 已在非阿贝尔群上实现（Dittrich 等人），代码可参考其已发表工作的附录或开源项目。我们可基于 iTensor 或 TensorNetwork 自行实现。

  • 6j 符号计算：sl2cfoam-next 已成熟，能高效计算 SU(2) 和 SU_q(2) 的 6j/15j 符号，支持任意半整数自旋和量子群参数 kk。其 C++ 接口可嵌入到我们的程序中。

  • 数值精度：现代计算机对双精度浮点数的 SVD 和矩阵运算支持良好，误差可控。关键奇异值的收敛性可通过自适应截断保证。

  • 计算资源：阶段II（2+1维 SU(2)_k）对中等规模晶格（如 32332^3）的 TNR 迭代，可在单台多核服务器（如 64核、256GB内存）上运行，时间约数天至数周。阶段III（4D）需超算支持，但初期可从小规模（如 444^4）开始验证原理。

4.2 科学可行性

  • 已有数值证据：Dittrich 等人已在 SU(2)_k 量子群自旋网中发现大量非平庸固定点，并验证了其扩展相区。这为我们寻找固定点提供了坚实基础。

  • 普适校准的预期：根据我们的理论推导，满足 Rn=nR_n = n 的固定点正是这些非平庸固定点中的一部分，且整数 nn 可能对应于不同的拓扑荷。这为数值验证提供了明确目标。

  • 潜在风险：

    • 从边张量提取群元 UeU_e 可能涉及逆问题，存在多值性。可改用威尔逊圈的期望值代替直接计算，因为 ⟨Wγ⟩\langle W_\gamma \rangle 在固定点处也应与 Φgtot\Phi_g^{\text{tot}} 相关。

    • 质量 MtotalM_{\text{total}} 的提取较复杂，尤其在离散网络中缺乏直接定义。替代方案：利用能量-动量张量的期望值，通过转移矩阵的最大特征值得到总能量，再求质量。这需要构建系统的哈密顿量，但自旋泡沫模型的哈密顿形式尚不完善。可先在小规模系统中试探性采用简单近似，如认为每个顶点质量相等且与局域几何相位梯度有关。

    • 量子群形变下，自旋截断 jmax⁡j_{\max} 有限，外推需要小心处理。

六、结论

本数值实验方案基于成熟的张量网络技术和自旋泡沫库，旨在直接验证相位网络理论的核心预言：固定点处满足 Rn=nR_n = n。尽管存在一些技术挑战（如质量的提取），但通过合理的近似和交叉验证，有望获得可靠结果。若成功，将首次在离散量子引力模型中获得连续极限存在的数值证据，并证实普适标度校准原理的普适性。此实验不仅是 PNT 理论的关键检验，也将为量子引力数值模拟开辟新范式。
